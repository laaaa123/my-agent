AI 情感助手与超级智能体项目
作者：zmy
项目定位：AI 应用实战项目（情感助手 + 超级智能体）
技术方向：Spring AI / RAG / Tool Calling / MCP / Agent

项目介绍
本项目是一套面向真实业务场景的 AI 应用工程，核心由两部分组成：

AI 情感助手应用
支持多轮对话、会话记忆持久化、会话级知识库问答、工具调用与流式输出，解决用户在情感、沟通、关系决策等场景中的问题。

AI 超级智能体
支持任务拆解、自主规划和多工具协作执行，可扩展到搜索、网页分析、内容生成、文档输出等复杂任务。

项目目标不是做 Demo，而是沉淀一套可复用的企业级 AI 应用架构，包括：对话编排、知识检索策略、会话隔离、可观测性、前后端协同与工程规范。

1. 应用编排层
   负责意图路由、对话分发、结果统一输出。
   典型模块：LoveApp（已重构为编排职责）

2. 知识检索层
   负责召回策略、会话隔离、回退机制、命中日志。
   典型模块：KnowledgeRetrievalService

3. 提示词治理层
   统一管理系统提示词与业务提示模板，避免散落在业务代码中。
   典型模块：EmotionalAssistantPrompts

4. 入库处理层
   负责文档解析、切分、文本清洗、向量入库、分片统计。
   典型模块：KnowledgeBaseIngestionService

5. 会话与记忆层
   负责会话创建、消息落库、记忆策略（摘要 + 最近消息）。
   典型模块：Chat Session / Chat Memory 相关服务

核心业务流程
流程一：对话请求
用户输入 -> 意图路由 -> 普通对话 / 知识问答 / 工具调用 -> SSE 返回前端

流程二：知识库问答
上传文档 -> 文档解析与入库 -> 检索策略召回（会话 + 公共）-> 组装上下文 -> 生成回答

流程三：会话隔离
会话创建 -> 文档绑定会话 -> 检索按会话过滤 -> 避免跨会话文档串读
